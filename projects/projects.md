# Projects

This folder contains summaries and links to all projects built during **Hack4Freedom Kaduna 2025**.

Each project was developed by a team of participants as part of the two-week hackathon and is:
- Open-source by default
- Built in public GitHub repositories
- Focused on solving real local problems using Bitcoin and freedom technology

This directory serves as both a record of the work completed during Hack4Freedom Kaduna and a starting point for continued development beyond the hackathon.
